# Versioni bloccate per Python 3.8 a 32 bit su Windows 7, su CPU senza AVX.
#
# Le impronte (--hash) sono quelle delle wheel cp38-win32 su PyPI, controllate
# il 26/10/2026: pip installa esattamente questi file o si ferma. Su un PC di
# sviluppo Linux o a 64 bit le impronte non corrispondono (le wheel sono
# altre): li' si installano le stesse versioni senza impronte, vedi
# software/CLAUDE.md.
#
# Il perche' delle versioni:
#
# numpy 1.22.4   NON la 1.24.4. La 1.24.x per win32 usa istruzioni AVX senza
#                controllare la CPU: sulla macchina di riserva Python moriva con
#                c000001d (istruzione non valida). Dalla 1.22.4 in giu' nessuna
#                istruzione AVX non protetta. Decisione 0003.
# scipy 1.9.1    la 1.9.2 smette di pubblicare wheel a 32 bit; controllata,
#                niente AVX. Pretende numpy<1.25.
# Pillow 10.4.0  ultima con wheel cp38-win32; controllata, niente AVX.
# tifffile       pura Python, ultima che supporta il 3.8.
# openpyxl       registro ordini in Excel, pura Python. Senza, esce in CSV.
#
# Oltre queste versioni su PyPI c'e' solo il sorgente, e pip prova a
# compilarlo: e' li' che nasce "mesonpy requires at least Python 3.10". Per
# questo si installa sempre con --only-binary=:all:.

numpy==1.22.4 \
